# 이 종목을 가장 많이 보유한 ETF는?

국내 상장 ETF의 종목별 보유 정보를 검색하고 비교하는 모바일 웹사이트입니다. React와 Vite로 만든 정적 사이트로, 회원가입이나 로그인 없이 이용합니다.

## 웹사이트

GitHub Pages에서 제공하는 주소: <https://inandout-kr.github.io/etf-finder-share/>

## 실행과 빌드

Node.js 20.19 이상 또는 22.12 이상을 권장합니다.

```sh
npm ci
npm run dev
npm test
npm run typecheck
npm run build
npm run preview
```

빌드 결과는 `dist/`에 생성됩니다. Vite의 상대 경로 설정으로 GitHub Pages의 프로젝트 하위 경로에서도 동작합니다.

## 데이터

사이트는 정적 JSON 스냅샷을 GitHub Pages에서 불러옵니다. 검색어와 검색 기록은 브라우저 안에서 처리하며 서버로 보내지 않습니다. 사이트를 제공하기 위해 GitHub에 데이터 요청이 발생하며, GitHub의 서비스 및 보안 관련 접속 기록 정책이 적용될 수 있습니다. 이 프로젝트는 광고, 분석 도구, 추적 쿠키, 로그인 기능을 사용하지 않습니다.

현재 포함된 데이터는 **2026-10-19 기준** 국내 상장 ETF **1,176개**, 구성종목명 **14,016개**입니다. 데이터는 자동 갱신되지 않습니다. 갱신할 때는 기존 `../etf-finder/dist`의 최신 스냅샷을 읽어 `public/data`에 복사한 뒤 빌드하세요.

```sh
npm run sync:data
npm test
npm run build
```

데이터 원본은 네이버 금융과 WiseReport에서 제공하는 국내 상장 ETF 구성종목 정보입니다. 자료의 기준일과 출처, 산출 기준은 사이트 하단의 **데이터 출처 · 산출 기준**에서 확인할 수 있습니다. 보유비중 또는 추정금액이 제공되지 않으면 임의로 0으로 처리하지 않습니다. 모든 보유비중이 없는 종목은 1CU당 보유수량순으로 보여주며, ETF마다 CU 규모가 달라 수량을 비중으로 해석할 수 없습니다.

## 개인정보 안내

종목명 검색은 브라우저 안에서 처리합니다. 검색어를 저장하거나 데이터 요청에 포함하지 않습니다. GitHub Pages는 사이트와 데이터 파일을 제공하므로 접속 정보는 GitHub의 서비스 정책에 따라 처리될 수 있습니다. 실제 호스팅 위치가 달라지는 경우 이 안내와 사이트 내 개인정보 안내를 함께 갱신하세요.

ETF 구성정보를 비교하기 위한 참고 자료이며 투자 권유가 아닙니다. 현재 가격이나 운용사의 최신 보유 내역과 차이가 있을 수 있으므로 투자 판단 전에 최신 공시를 확인하세요.
